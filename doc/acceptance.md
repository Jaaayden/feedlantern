# v0.2.0 验收记录

本文件随实际验证更新，不把测试样例通过等同于兼容所有网站。

## 已验证

- 新增管理界面端到端验收通过：视图偏好、RSS 频道名称、批量创建及备份下载。
- 两个用户指定公开网站回归通过：上科大科研进展识别 14 项，Pepper 博客主列表识别 10 项，均返回高可信推荐。

- 33 项单元、DOM、集成测试通过，包括批量自动创建/确认/重试去重、跨主密钥备份恢复、失败事务回滚和频道名称持久化。
- 新管理 API 专项测试通过：登录边界、空名称、RSS 缓存更新、批量部分失败、配置重复跳过、备份错误密码、恢复后撤销会话。
- 原有 11 项端到端测试通过：自动识别、Cookie 隔离、恶意重定向、手动字段保持、历史保留、复制及密钥轮换。
- Compose 语法检查、TypeScript 检查和生产构建通过。
