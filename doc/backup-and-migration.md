# 备份与迁移

## 完整备份

设置 → 完整备份，输入当前操作管理员的密码及至少 12 字符的独立备份密码，下载加密 JSON。请将备份密码单独保管；丢失后无法恢复。

备份包括所有用户的用户名、角色、启用状态、密码哈希及数据归属，以及订阅规则与名称、Cookie、RSS 密钥、历史和管理员视图偏好；不包括登录会话、截图、日志和未完成任务。文件使用 scrypt 派生密钥与 AES-256-GCM 加密。

完整备份格式现为 version 3，包含多个管理员及所有用户的个人 Bark 设置，支持恢复 version 1、2 备份；旧备份里的全部订阅和凭据归备份中的管理员。新版备份不能由旧版程序恢复。恢复后全部用户需要重新登录，停用账号仍保持停用。普通用户保存在浏览器中的视图偏好不随备份迁移。

## 多用户数据库升级

启动时事务迁移 SQLite 至 `user_version=8`，保留原管理员用户名和密码，原订阅、Cookie 与批量任务全部归原管理员；RSS 密钥和历史不变。从单用户版本升级时旧登录会话被撤销。v0.5.1 移除单管理员约束，原全局 Bark 迁移给原管理员，保留账号与 RSS 地址。升级前按维护指南停机备份完整数据卷；如需退回旧版，应同时恢复升级前的数据卷，不要让旧程序直接读取新版数据库。

## 完整恢复

已有实例：设置 → 完整恢复，选择文件、输入当前操作管理员的密码与备份密码，预览数量、版本、账号及安全配置差异，确认覆盖。

新实例：初始化页 → 从备份恢复，使用目标主机一次性设置码和备份密码。完成后使用**备份中的管理员账号密码**登录。

恢复时暂停新请求、等待后台操作完成并关闭编辑会话；在数据库事务中整体替换应用数据。错误密码、格式错误和事务失败保留原数据。恢复成功使旧会话失效。备份使用目标服务器的密钥重新加密，不需要复制旧 `master.key`。

运行地址、端口、文件路径与安全网络配置保持目标实例设置。导入不自动扩大私网白名单；确需同等网络权限时，审核差异后按配置文档修改目标环境。

## 更换服务器

1. 旧实例导出完整备份，记下版本及外部域名。
2. 新服务器部署相同或兼容版本，初始化页恢复。
3. 配置 Nginx 和相同 `PUBLIC_ORIGIN`，检查登录、Cookie 抓取和历史。
4. 切换原域名 DNS，保留订阅 ID 和密钥后阅读器地址无需更改。
5. 如使用新域名，批量复制新 RSS 地址并更新阅读器；仅保留 ID 和密钥不能保留旧域名前缀。

切换前可暂停旧实例订阅，验证新实例后再停旧服务，避免两个实例持续抓取。

## 轻量配置

轻量配置导入导出仅管理员可操作，订阅和个人通知部分只涉及操作管理员自己的数据，不导出其他用户的密钥。配置导出含订阅名称、规则、加载参数、刷新间隔及启停状态，不含凭据、RSS 密钥、管理员或历史。网址本身仍可能包含私人信息。

配置导入先预览再确认，追加新项目，按规范化网址与字段规则跳过完全重复项，不覆盖现有订阅。新项目生成新密钥；需要 Cookie 的项目暂停，需编辑绑定凭据后恢复。

网页完整恢复请求上限 100 MB，轻量导入上限 10 MB；界面为传输开销预留余量。超过上限时使用停机数据卷备份，保留数据库和 master.key，见维护指南。

抓取日志、故障去重状态和 Bark 待发送队列属于本机运行历史，不包含在配置导出或网页加密备份中。恢复备份会清空这些记录，避免重放旧告警；后续实际抓取重新生成日志。应用及服务器设置、个人 Bark 地址随完整备份一起迁移；轻量配置仅包含操作管理员本人的 Bark 地址；完整备份跨服务器恢复时会重新加密 Bark 地址。普通配置含 Bark 密钥明文，请私密保存。

新版配置（version 2）导入前预览将覆盖的应用和服务器设置，确认后与订阅一起保存；旧版配置（version 1）没有应用设置时保留当前设置。不含应用设置的旧备份恢复时使用默认通知设置并保留目标服务器设置；含全局 Bark 的旧备份将其迁移给原管理员。监听地址与端口恢复后重启生效。
