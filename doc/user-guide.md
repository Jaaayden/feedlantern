# 使用指南

## 创建订阅

登录后选择“新建订阅”，输入网址及可选 Cookie，点击“打开并自动识别”。软件寻找重复列表并匹配标题、链接及可选字段。明确结果直接预览，有多个合理列表时选择候选；缺少可选字段不阻止保存。

在“调整匹配”中可点选网页内容、切换条目容器、清除错误字段或编辑 CSS 选择器。修改后重新预览，匹配有效才可保存。手动字段会在重新识别时保留，除非明确选择替换。

网页加载后会逐屏滚动，触发滚动入场动画和视口内的延迟加载，再恢复原位置。编辑预览、批量识别和后台刷新使用相同流程；滚动最多 20 步或 8 秒，到底部稳定后提前结束。只处理当前页，不点击“查看更多”或翻页，不能保证完整采集无限滚动或虚拟列表。

## 订阅名称

打开订阅详情 → “订阅设置” → “订阅名称”。保存后同时更新订阅列表名称和 RSS 频道标题，无需打开目标网页；地址、历史和调度不变。编辑匹配中的名称也使用同一设置。升级时若旧版本两个名称不同，会保留阅读器名称并同步到列表。阅读器已保存的名称或用户自定义名称可能不会自动更新。

## 日常管理

默认使用列表，可切换卡片并记住偏好。两种视图支持直接复制 RSS、编辑、查看详情与选择。搜索后全选只作用于当前结果，改变搜索会清空选择。

批量复制每行一个 RSS 地址；支持暂停、恢复、刷新和删除。失败逐项显示，成功项目不回滚，失败项保留选择。选择较多订阅时，界面自动分批请求；立即刷新逐项进行，避免单个长请求超时。删除会同时删除该订阅历史；密钥轮换会立即撤销旧 RSS 地址。

## 批量添加

“批量添加”中每行一个网址，最多 100 个；先修正无效行，重复行会跳过。可统一刷新间隔并逐行选择 Cookie。

明确结果自动创建；歧义结果显示候选样例，点击“打开并调整匹配”后重新加载验证并保存。失败可重试，已存在网址复用原订阅。任务在后台执行，关闭页面不会停止，重启后恢复。取消只影响未开始的项。结果页可以复制整批订阅地址。

## Cookie

在“Cookie 凭据”中粘贴 Cookie 字符串或 OpenCookie 兼容 JSON，可以上传 JSON 文件。凭据可以命名、替换并供多个订阅引用；只有域名兼容时才会携带。过期或失效需从已登录浏览器重新导入。服务不提供交互登录或验证码处理。

## 兼容范围

支持普通 DOM 列表、动态渲染和 Cookie 页面。暂不支持全文、自动翻页、无限滚动采集、iframe 内部点选、封闭 Shadow DOM 和 Canvas 内容。规则失效时保留历史，修复前不会静默替换规则。
